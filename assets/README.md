# Assets

Novi WebAR demo očekuje 15-sekundni video na ovoj putanji:

`assets/krapina-neandertalac-15s.mp4`

Datoteka je 15-sekundna rekonstrukcija krapinskog neandertalca / lokaliteta Hušnjakovo brdo. Nakon što je MP4 prisutan na ovoj putanji, glavni `index.html` može se prebaciti na novu markerless WebAR verziju.
